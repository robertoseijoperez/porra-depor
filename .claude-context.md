## 2. Arquitectura General

### Flujo de datos

```
Componente Angular
      ↓
Servicio (GoogleSheetsService)
      ↓
Google Sheets API v4
      ↓
Hoja de cálculo compartida (backend)
```

### Principios clave

- **Standalone components**: No hay AppModule, todos los componentes son independientes
- **Servicios centralizados**: GoogleSheetsService maneja toda la lógica de API
- **Environment files**: Variables sensibles (API keys) en `environment.ts` y `environment.prod.ts`
- **Routing módular**: Rutas definidas en componentes principales
- **Diseño temático**: Royal blue, fuentes Anton/Oswald, imágenes locales en `assets/players/`

## 5. Componentes Existentes

### `clasificacion` (Pantalla de clasificación)
- **Ubicación**: `src/app/clasificacion/`
- **Responsabilidad**: Mostrar tabla de rankings con puntuaciones totales
- **Inputs**: Datos de jugadores y puntuaciones (desde service)
- **Outputs**: Click en jugador → navegación a `/jugador/:nombre`
- **Dependencias**: GoogleSheetsService, Router
- **Notas**: Columnas: Posición, Nombre, Aciertos, Fallos, Puntos Totales

### `jornada-list` (Lista de jornadas)
- **Ubicación**: `src/app/jornada-list/`
- **Responsabilidad**: Listar todas las jornadas con resumen básico
- **Inputs**: Array de jornadas (desde service)
- **Outputs**: Click en jornada → `/jornada/:id`
- **Dependencias**: GoogleSheetsService, Router
- **Notas**: Mostrar jornada número, fecha, equipo rival, resultado si existe

### `jornada-detail` (Detalle de jornada)
- **Ubicación**: `src/app/jornada-detail/`
- **Responsabilidad**: Mostrar predicciones de todos los jugadores para una jornada
- **Inputs**: ID de jornada (desde route params)
- **Outputs**: Comparar predicciones vs resultado real
- **Dependencias**: ActivatedRoute, GoogleSheetsService
- **Notas**: [Describe layout: tabla, tarjetas, etc.]

### `jugador-detail` (Detalle de jugador)
- **Ubicación**: `src/app/jugador-detail/`
- **Route**: `/jugador/:nombre`
- **Responsabilidad**: Mostrar estadísticas de un jugador en la temporada
- **Secciones**:
  - Header con foto dinámica (`public/assets/players/[nombre-normalizado].jpg`, fallback a avatar)
  - Stats generales (aciertos, fallos, porcentaje)
  - Tabla histórica de predicciones
- **Dependencias**: ActivatedRoute, GoogleSheetsService
- **Bug conocido**: Diacríticos en nombres (María) → normalización en `utils/normalization.ts`
- **Notas**: Foto fallida usa lógica de encabezado; foto nombrada como `maria.jpg` (sin acento)

### `pronostico-registro` (Registro de predicciones)
- **Ubicación**: `src/app/pronostico-registro/`
- **Estado**: EN DESARROLLO
- **Responsabilidad**: Permitir a cada jugador registrar su predicción para la próxima jornada
